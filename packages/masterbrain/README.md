# Masterbrain — Platform AI module

Maintained in the Airalogy Platform repository. Python imports retain the `masterbrain` name; product development and delivery use the Platform source revision.

See [AI development](../../docs/en/masterbrain-development.md) / [同仓开发](../../docs/zh/masterbrain-development.md) for installation, testing and production builds.

The import baseline and file mapping are in `migration-source.json`; original documentation and changelogs are retained under `history/`. The Apache-2.0 license is preserved in `LICENSE`.

This internal package is not independently published. Model calls and proposals do not authorize business operations; the Platform host retains identity, permissions, validation and persistence.

Studio, desktop packaging and local workspace/library endpoints remain as historical source in the original Masterbrain repository and are no longer actively maintained. This module provides the AI service consumed by Platform.
