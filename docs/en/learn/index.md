## Four useful concepts

- **Project** groups Protocols, documents, materials and knowledge around a research goal.
- **Protocol** is an editable, versioned plan and field structure. It may be written for one experiment or reused.
- **Record** holds data submitted against an exact Protocol version; corrections retain revision history.
- **Document** is flexible writing for ideas, plans, observations and meetings. Add fields when useful, without preparing a separate Protocol first.

A Lab owns team permissions and resources. Single-Lab deployments select the configured Lab for you; members usually start in a project. Personal documents are private to their owner. Shared content follows scope permissions: **a public project does not make every document or material public.**

## Start with Aira

When AI is enabled, describe your goal, then review, confirm and save the result. All three demonstrations call a real model using synthetic data.

1. [Create and refine a Protocol with Aira](./aira-protocol): describe → draft → refine → validate and preview → save.
2. [Fill a Record in conversation](./aira-record): ask about fields → provide values → review each suggestion → edit → submit.
3. [Ask Aira and save an analysis](./aira-analysis): ask → adopt a proposal → confirm computation → inspect sources → save the method.

Aira helps draft, fill and explain. Platform still confirms permissions, destinations, validation and execution. The manual paths below remain available without AI.

## Four manual tasks to follow

1. [Submit and find your first Record](./first-record): save, verify and revise.
2. [Write your first research document](./first-document): choose a template, write and find it again.
3. [Create your first Protocol](./first-protocol): edit, validate, preview and save.
4. [Import your first CSV](./first-import): use the template, resolve errors and confirm.

Each task includes a real UI video, AI-generated Chinese narration, Chinese/English captions, written steps and a result check. Audio starts only when you press play; mute or switch captions at any time. The recordings use a Chinese UI and synthetic data; AI lessons require model access; the four manual tasks require neither AI nor equipment. Use a dedicated demo project, separate from research data. Reuse the example Protocol if it already exists in that project.

## A short checklist for administrators

- Establish the Lab, project and appropriate member permissions.
- Import the example Protocol into a dedicated demo project for new members.
- Invite colleagues and tell them which project or Protocol to start with.

Tutorials do not create projects, expand permissions or submit example values into real research automatically.
