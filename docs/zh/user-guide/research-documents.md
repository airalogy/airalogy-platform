# 研究记录与原始资料

项目默认进入**概览**，可直接继续最近研究记录。选择**新建文档**，从空白或内置、自定义模板开始；项目内还可选择**使用已有 Protocol**复制准确版本的方法。无需先建立共享 Protocol。首页工作台也可直接打开自己的最近文档。

## 写作、保存与回访

使用 AIMD 可视化编辑或源码模式，按需加入字段。正文未完成、语法待修正、字段未填完均可保存。**已保存**表示内容已落库，不代表校验通过或科学结论已验证。恢复历史会生成新修订；并发编辑发生冲突时拒绝覆盖另一份已保存内容。

文档也会出现在日志时间线中，两种视图引用同一条内容。已有 Log、Knowledge 正文不会自动转换或重新解释。标签和集合帮助整理，不改变权限。

## 完成一次实验

在方案中写明计划参数，在对应字段中填写实际测量值，在实际操作和偏差段落中补充发生的情况。加入字段不要求发布共享 Protocol。已有值时修改定义需要确认影响；删除字段仍保留旧值，须在**检查已填数据**中明确移除，历史修订仍然可查。

**校验**检查当前已保存定义和数据；**提交结果**预览并固定正文、字段定义、数值及附件摘要。校验失败不创建结果。此结果属于文档本身，不是旧的 Protocol Record，不会自动进入 Protocol 的 Records 分析。之后编辑会形成新的工作修订，不覆盖既有提交证据。**再做一次实验**复制方案和来源，不复制测量值、签名或附件。

首期支持文本、整数、数值、布尔、日期、日期时间、可空值、枚举及受支持约束的表格。需要 Python、自定义类型、文件或资源解析、采集器、Assigner 的方法继续使用普通 Protocol 运行环境；打开研究文档不会执行这些能力。

## 归档已有资料

在**资料**中上传原始照片、PDF、表格和仪器文件，填写来源说明；知道历史发生日期时可以补充，它与上传日期分开保存。支持安全预览的 PDF 和图片可直接查看，其他格式仍可下载。通过文档的**关联资料**入口关联原件。

文本 PDF、UTF-8 文本可提取后由用户检查，再建立附带原件的新文档。这是确定性文本提取，不是 OCR。手写笔记和纯扫描材料可以先归档、人工转录；提取值不会自动提交为实验测量。

此处上传 CSV 只是归档文件，**不会创建 Records**。创建正式 Record 仍使用 Protocol 的 CSV 模板和严格导入流程，失败时零 Record 写入。

## 导出、恢复与复用

**导出文档**下载带格式版本的 ZIP，包含当前 AIMD、字段值、附件字节及校验摘要。**导入文档归档包**检查完整性、预览保存范围后，生成独立工作文档，保留当前内容，不继承原审核或提交的权威状态。原文档历史修订仍在来源平台保留。归档包限制 64 MiB，更大的原件可单独下载。

**提炼资产**先让用户整理正文，再创建 Knowledge 草稿或可下载的 Protocol 草稿包。复用方法时明确填写参数默认值，清除不应共享的观察内容。已填测量值和附件不会自动进入目标资产，来源修订私下保留；Knowledge 审核与 Protocol 发布继续使用原有流程。

## 可见范围与当前边界

个人文档私有；项目和实验室使用现有成员权限。公开项目不会自动公开笔记或资料。只有作者可以修订文档；附件须属于相同受众，每次读取、导出再次鉴权，复制和物理去重均不授予原文件权限。

首期不含 OCR、手写识别、实时协作、自动跨实验室共享及文档结果的完整下游分析。关闭 AI 后，写作、资料归档与结果提交仍可用。后续阶段见 [RFC #21](https://github.com/airalogy/platform/issues/21)。

## 文档模板

入口统一为**新建文档**。在弹窗中选择空白、实验记录、会议记录或研究进展模板，预览正文并确认保存位置后创建。项目内的“使用已有 Protocol”也放在这个入口的来源选项中，仍使用准确的协议版本。模板是起点，生成的文档可自由修改，不要求发布 Protocol。

在**文档模板**标签中可新建自己的模板；也可以在文档中选择**另存为模板**。填写名称、用途，使用可视化或源码编辑整理章节、说明和字段，再选择个人、项目或实验室范围。先预览，确认后才保存。正文中的具体观察和私有链接需要用户检查并移除；已填写的字段值、附件引用列表和提交状态不会自动带入模板。需要重复使用的计划参数，应在 AIMD 字段定义中明确设置默认值，例如：

```text
{{var|temperature: float = 25, ge=0, le=100}}
```

默认值和字段约束由服务器检查，未填写的结果字段仍保持空白。

个人模板仅自己可见。项目与实验室模板仅向有权成员开放；公开项目不会公开模板。创建模板沿用文档的写入权限：项目按现有成员角色授权，实验室默认由 Owner/Manager 或获授日志发布能力的成员创建。作者或相应范围管理者可编辑、归档和恢复模板。只读成员可查看模板，并在自己有写入权限的范围创建新文档。每次读取、复制和使用都重新校验权限。

**复制到其他范围**创建独立模板，需再次预览共享范围和内容，不移动原模板或扩大原文档、附件的权限。修改模板生成新版本；从模板创建的文档保留使用的版本和内容，不会随模板更新而变化。旧预览遇到模板更新会被拒绝，需要重新查看。归档只阻止以后使用模板，不删除既有文档；可在“查看已归档”中恢复。

## 可见范围与按时间浏览

范围选择器决定文档保存到个人、项目还是实验室。列表、新建窗口和阅读／编辑页面明确显示保存位置和受众：个人文档仅自己可见；项目文档由有权项目成员和所属实验室所有者、管理员查看；实验室文档由本实验室成员查看。工作草稿也遵循此范围，正文仍由作者修订，公开项目不会自动公开这些文档。

**记录日期**表示实验、会议或研究实际发生日期，支持补录历史内容。修改正文只改变**更新于**，不会将旧实验移动到今天。日期区间和按天分组使用当前设备时区，并正确处理夏令时。**最近修改**便于继续工作；**按记录日期**便于回顾科研过程。展开**日历定位**可查看当前搜索和类型下每一天的文档数量，选择日期后筛选当天内容，通过**清除日期**恢复较大的浏览范围。

点击文档即可阅读正文、已填字段和附件。桌面显示左侧列表与右侧阅读区，窄屏一次显示一篇文档。**上一篇／下一篇**可跨页继续，沿用范围、搜索与日期条件。选择**编辑文档**进入原编辑器，保留自动保存和未保存内容离开保护；返回后恢复浏览条件。若修改日期或标题使文档不再满足原筛选，页面会说明原因，不会擅自清除筛选。阅读不修改或提交数据；日志与文档继续引用同一条记录及发生时间。

## 简洁写作与按需操作

主导航的**文档**进入个人文档，也可切换项目或实验室范围。新建默认显示常用模板；**浏览更多模板**提供个人、项目、实验室及项目内的 Protocol 来源。使用过的自定义模板会在本机当前账号的**最近使用**中显示，每次打开仍从服务器重新检查权限和当前版本，不缓存模板正文。记录日期默认今天，需要补录历史时展开设置。

编辑页以标题和正文为主，自动保存状态始终可见；失败时可重试，未保存内容仍有离开保护。可视化编辑使用编辑器自带的输入框插入功能，源码模式保留添加字段帮助。标签、集合、附件和来源在**详情**中。**更多**按历史与结果、复用与整理、文件分组提供原有操作。普通写作不要求提交；需要固定实验结果时展开**检查与提交实验结果**，原有校验、预览、确认和不可变快照机制保持有效。

列表默认显示内容、搜索与排序；**筛选**中提供类型、日期和日历。已启用的条件始终显示摘要，并可一键清除。列表和阅读仍保留原日期、权限及返回行为。

首页沿用真实待办优先顺序，并将最近文档与本机 Record 草稿按更新时间比较，提供继续写作或继续填写。最近文档列表可直接进入编辑。项目概览保留最近内容和新建入口，项目标签统一使用“文档”；新建时直接继承当前项目。

文档列表右上角始终保留有权限的新建入口，**更多**提供文档模板和归档包导入。没有文档时显示开始提示；有文档后，搜索、排序和筛选集中在同一工具栏。无匹配结果时可清除搜索和筛选，不会创建文档或改变保存范围。

在任意工作区可使用页头 **新建 → 新建文档**。从项目、实验室或已有文档进入时，先检查目标写入权限，再在相同范围打开现有模板选择弹窗；从首页等全局页面进入时默认个人私有空间，不会因为只有一个实验室而自动共享。创建前请核对保存位置和可见范围。导航菜单用于打开已有内容，“新建”用于创建内容；项目和实验室创建放在常用内容操作下方。
