# 开始使用 Airalogy Platform

第一次来？先打开[入门与演示](../learn/)，按“已有 Protocol、写文档、准备实验、导入表格”选择路径。

Airalogy Platform 将研究流程、按照流程采集的数据以及参与人员持续关联起来。不同机构可采用开放注册、邀请加入或统一分配账号等不同方式；Community Edition 与私有化实例中的核心研究工作方式保持一致。

## 登录或加入实例

- 如果实例允许自助注册，请按注册页提示创建账号，然后登录。
- 如果实例采用邀请制，请使用实验室管理员提供的邀请链接。已有账号可在登录后接受邀请，新用户通过邀请流程创建账号。
- 如果注册已关闭，请向实例运维人员或实验室管理员确认账号开通方式。

不要复用其他服务的密码。密码重置链接通常是短期有效的敏感信息，不要转发给他人。

## 理解工作空间

Platform 使用四类相互关联的资源：

| 资源             | 用途                                               |
| ---------------- | -------------------------------------------------- |
| Lab（实验室）    | 承载顶层工作空间、成员关系和治理规则。             |
| Project（项目）  | 围绕研究任务、团队或目标组织工作。                 |
| Protocol（协议） | 定义要执行的流程以及需要记录的结构化字段。         |
| Record（记录）   | 保存一次执行中已经完成或正在填写的 Protocol 数据。 |

有的部署只显示一个固定 Lab，有的部署允许用户加入多个 Lab。Project 和 Protocol 还可有更细的访问规则，因此能看到 Lab 不代表能查看其中所有资源。

已启用经营的组织可为项目单独授权，从签约前的投入开始跟踪成本与现金收付。[项目经营与经营总览](./project-operations)

## 从首页继续工作

登录后的首页优先展示“我的项目”：置顶项目在前，其余按你最近访问的时间排序。首次使用没有访问历史时，显示可访问项目，并明确提示先选择项目；其他成员修改项目不会改变你的访问顺序。

电脑顶栏左侧可切换首页、项目、协议、文档和知识。「更多」包含科研任务和日志。右侧的「新建」打开创建菜单。手机上，点当前栏目名切换页面，点头像可找到语言设置和已启用的 Aira。

在首页点击「向 Aira 提问」可展开右侧对话框。侧栏的「全部对话」会在新标签页打开 Aira 专页，首页草稿留在原页。专页的「账号历史」列出当前账号保存的通用对话，换设备登录后可以继续。手机上先点「聊天记录」。旧版本可核实归属的服务端对话也在这里，仅存在旧浏览器、无法核实归属的缓存不会自动归入任何账号。

- 点项目名进入概览；项目导航依次为概览、协议、文档、资料、知识。
- 点“继续上次工作”直达最近的文档、协议页面或 Record 报告。文档、协议快捷链接保留所在项目上下文。
- 有兼容的本机 Record 草稿时，显示“继续填写 Record”和“保存于本设备”。草稿内容不会随访问记录上传；换设备只能回到最近的页面，无法恢复另一设备尚未同步的填写内容。
- “我的文档”独立于项目，个人文档仅自己可见。无需先选择项目即可开始写作。
- 待处理区显示实际分配的工作、审批和结果审核。置顶资源及活动位于下方。

访问历史按账号隔离，最多保留 50 个项目；置顶使用已有的资源置顶功能。每次读取都会重新校验权限，删除或失去权限的资源不会继续暴露标题和链接。数据库迁移 `0081_project_visits` 只新增导航记录，不修改已有研究数据。

## 建议的首次使用流程

1. 进入实际承担研究工作的 Lab 和 Project。
2. 选择已有 Protocol；如果角色允许，也可以新建 Protocol。
3. 记录前检查 Protocol 的说明、字段、步骤、检查项和当前版本。
4. 新建 Record，填写要求的值，按需上传文件，然后保存或提交。
5. 重新打开 Record，确认值、文件和所属上下文正确。
6. 通过 Platform 的成员与访问控制将 Project 或 Protocol 分享给协作者。
