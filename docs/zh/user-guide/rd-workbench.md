# 用研发工作台跟进一个项目

研发工作台适用于硬件、软件、方法研究或实验室协作。进入 **项目 → 事项**，可以直接创建需求、任务、问题和里程碑，无需先创建 Protocol 或开启 AI。协议仍在项目的靠前入口；需要标准化执行时再关联它。

在「组织管理 → 成员」中，所有者和有相应权限的管理员可设置成员的组织内显示名。清空后恢复个人昵称。个人备注仅本人可见。会议参会人和事项负责人按组织内显示名选择，账号关联随账号 ID 保存。更名后既有任务仍属于原账号，已保存的会议保留当时记录的参会人姓名。

## 从一个真实目标开始

例如开发一副眼镜，可以先创建“完成第一版光学样机验证”：

1. 写清目标和完成条件，例如“形成测量报告，并由负责人确认下一版改进项”。实际指标由团队确定，平台不代填专业判定规则。
2. 指定负责人，按需添加协作者、优先级和计划起止日期。负责人可以暂不分配；创建者仍保留在历史中。
3. 把采购、结构设计、固件和测试拆成独立事项，通过依赖关联。同一事项只保存一份状态，列表、看板和计划时间轴读取同一来源。
4. 从事项中创建项目方案文档，或者关联已有文档、Protocol、Record、资料、分析报告和科研任务。文档、Protocol 和 Record 必须固定版本。
5. 在“讨论与进展”中记录实际进展、测试结果和决策。首页会展示分配给自己的未完成事项，点击即可继续。

创建方案文档会先保存一份普通项目文档；保存事项后才建立关联。即使关联保存失败，文档仍能在项目“文档”中找到。链接中的文档和 Protocol 可以查看被引用版本；继续编辑请前往对应的文档或协议入口。

## 日常快速入口

首页项目卡片可直接进入“研发事项”，项目“概览”也可直接新建。新事项先写标题即可创建，其余信息可逐步补充；抽屉底部始终显示保存按钮和是否已写入项目。

已保存事项分为“事项信息”和“讨论与进展”。记录日常进展无需翻过整张设置表；切换这两个区域会保留当前输入。修改事项信息后，应先保存，再提交活动，避免活动关联到旧版本。必填内容缺失时会明确说明并定位对应字段。

列表、看板和计划时间线共用关键词、负责人及状态筛选。可以筛选未完成或具体状态；没有匹配结果时清除筛选即可返回全部事项。加载时不会提前显示“暂无事项”。首页“我负责的研发事项”超过六项时，可继续加载其余事项。

在看板上可将卡片拖到目标状态列，也可点卡片上的「移动到」。移到「受阻」时确认阻塞原因；完成前需填写完成条件并完成前置事项。保存后的变更可在事项历史中查看。

## 如何判断状态

- **待开始、进行中、受阻、待审核、已完成、已取消**是工作安排状态。受阻时必须说明原因；完成前必须填写完成条件，并完成所有前置依赖。
- **测试通过／失败／无法判定**是独立的测试结论，需要依据和实际发生时间。
- **验收通过／不通过**由有审批权限的成员明确记录，需要理由和依据。
- “已完成”不会自动生成通过结论或验收。列表中的数量也不代表项目完成百分比。

计划时间轴仅展示填写了计划起止日期的事项，不猜测工期。实际测试/验收时间由用户录入，与系统录入时间分开保存。重开前置事项前，需先重开已完成的依赖事项，以免留下相互矛盾的完成状态。

## 讨论与决策

普通成员可以发布讨论、进展、测试结果和决策建议；有项目审批权限的成员可以采纳决策和记录业务验收。每条活动留存作者与录入时间，不能覆盖或删除。新决策可以替代旧决策，旧内容保留；替代已采纳的决策也必须经过采纳权限检查。

项目日志展示事项创建、状态变更、进展、决策、测试和验收事件，并链接回原事项。修改标题、调整排版或普通讨论不计为项目进展。

## 保存和多人协作

保存后显示项目位置和版本。多人同时修改时，过期版本会被拒绝，当前输入仍保留；查看服务器的新版本、比较内容后再决定如何保存。不会静默覆盖他人的修改。

浏览器会尽力保留未保存的事项和讨论输入，再次打开可恢复。它只是本机的恢复副本，不能替代成功保存，也不能跨浏览器同步。离开时会提示未保存内容；不要在公用设备上依赖这种恢复方式。

## 可见性

研发事项属于项目，沿用项目授权。即使项目公开，非项目授权成员也不能读取研发事项、讨论或其日志事件。只读成员不能写入；分配负责人和协作者不会授予新的项目权限。

证据只允许关联当前项目内有权访问的资产。个人或其他范围的内容须先按原有发布流程显式分享到项目。关联不会放宽 Restricted 权限；读取时重新检查来源权限，来源归档或权限撤销后显示不可访问，不泄露原链接和名称。

## 组织研发总览

单机构版从「项目 → 研发总览」进入，也可以点击首页「全部项目」旁的「研发总览」。原「组织管理」下的总览链接会打开同一页面。多机构版先进入相应组织，再选择「项目」旁的「研发总览」。

项目负责人取自当前项目所有者，使用组织内显示名。受阻项目优先列出，下一步取自未完成事项填写的内容。最近待完成的里程碑按最早计划结束日期选择，没有结束日期时用计划开始日期。点击阻塞、下一步或里程碑可打开原事项。

热力图显示最近 90 天的项目活动。点击日期按浏览器时区查看当天的活动、所属项目和来源；再次点击返回近期活动。组织所有者和管理员可用此页，会议、记录和其他来源仍按各自权限筛选。
