# 项目会议与研究活动

进入项目的“会议”板块，新建会议记录。默认记录已召开的会议，填写实际日期；具体时刻可选。补录历史会议不会因为今天录入而移到今天。会前可以先准备议题，计划时间可留空；尚未召开和已取消的会议不进入已发生的活动统计。

## 参会人员与可见范围

从项目成员中选择账户，或填写外部人员姓名、单位。可以区分已参会、已邀请、未参会与待确认。参会名单不自动授权。普通会议默认项目读者可见；选择“仅指定成员可见”时，创建者保留访问，其余成员需要明确授权。授权仍受项目权限约束，不会把外部人加入项目。创建者管理参与者与权限；可查看、可评论、可编辑分别设置。可见范围适用于纪要及其历史版本。

文档列表、历史、会议列表、活动图和事项中的来源引用都重新检查会议访问权限。会议在文档中使用同一份正文与修改历史。已有附件继续遵守自身可见范围，会议授权不会把项目文件变为仅参会人可见；需要限制附件时应先按文件权限处理。首版不包含外部账户邀请或访客共享。

## 纪要、补充意见与行动项

填写讨论、决定及依据、待确认问题和下一步，点击保存并核对反馈。并发修改时拒绝覆盖旧版本；保留当前输入，查看最新内容后再决定如何合并。关闭或离开页面前会提示未保存内容。意见独立追加，记录作者与时间，不会覆盖纪要。

保存纪要后，可关联已有研发事项，或输入行动项标题、负责人和计划日期直接创建事项。新事项按项目事项权限共享；只关联准确的会议版本，不把私有纪要正文复制到事项。没有会议权限的项目成员仍可跟进事项，但不能打开会议来源。重复提交同一个创建请求不会重复生成事项。列表显示事项当前状态；历史纪要保留当时的事实。下一次会议继续关联同一事项。

## 项目概览与活动回顾

概览的“研究活动”默认显示近 90 天热力图及近期活动。点击某天，下方切换为当天明细；清除日期回到近期活动。按会议、文档与日志、实验 Record、事项与研究进展、Protocol、知识筛选时，图和列表使用同一套权限与统计条件。进入完整活动可选择年份并分页浏览。

会议按实际发生时间归日，一场会议只算一次；修改正文和参会人不增加次数。图与明细使用当前浏览器显示的时区，无权查看的内容不进入数量。活动数量用于回顾，不代表研究质量或完成度。文档、任务、Protocol、Record 沿用各自的真实保存/提交事件，普通讨论和标题修改不冒充事项进展。

周期排期、提醒、实时共同编辑、录音转写与 AI 摘要留作后续扩展。普通会议无需创建 Protocol；需要标准化执行的评审或测试可关联已有 Protocol/Record。
