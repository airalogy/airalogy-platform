# Aira 个人记忆

个人记忆让 Aira 在新对话中沿用你明确选择的表达偏好。第一版支持**回答语言、详细程度、表达格式和解释方式**。它不会扫描过去的对话、自动推断习惯，也不会保存实验数值、患者资料或项目内容。

## 设置或通过对话记住

在账号设置中找到 **Aira 个人记忆**，或点击 Aira 输入框上方的 **个人记忆**。选择偏好后保存；清空某一选项会忘记该项，其他偏好不变。管理界面可以撤销刚才的修改。

也可以发送以下明确指令，可用逗号组合偏好：

- `记住：用中文回答，简洁回答`
- `以后请分步骤回答`
- `记住：详细解释，使用专业术语`
- `忘记回答语言`
- `忘记所有个人偏好`

这些指令由 Platform 确定性处理，不需要模型可用。不支持的内容会明确提示未保存，不会只保存半条指令。当前消息有更具体的要求时，以当前要求为准。

保存的偏好用于普通问答、Protocol 生成中的说明文字、已计算结果的分析解读。不会改变协议字段 ID、单位、类型、校验或计算。Recorder 的对话填表暂不注入这些偏好，保持当前消息提供实际值的严格来源要求。

## 不使用或删除记忆

- **关闭记忆并保存**：保留已有偏好，但后续请求不读取，也不接受对话记忆写入；可再次开启。
- **本次对话不使用记忆**：该对话后续不读取、不保存记忆。要重新使用，请新建对话。它仍是普通历史对话，不是无痕模式。
- **清除全部**：删除当前偏好，后续请求不再使用。旧请求重试不会把已清除的内容恢复。
- **导出**：下载当前偏好、来源和修改时间。修改记录仅保留操作时间、涉及的偏好类别和版本，不保留已删除的偏好值。

已经发出的模型请求、已生成回答、用户消息和浏览器本机对话历史不会被这些操作追溯删除；删除聊天也不等于删除个人记忆。管理界面与服务器分别保存状态，其他窗口有新修改时需要重新载入，避免覆盖。

个人记忆仅当前账号可管理，保存在当前 Platform 实例，不向 Lab、Project 成员共享，也不随外部 Agent 的项目访问令牌开放。记忆服务暂时不可用时，普通问答继续运行并提示未使用记忆；AI 关闭时，账号设置仍支持查看、修改、清除和导出。

自动生成的记忆候选、工作进展记忆和项目知识检索属于后续阶段，不包含在第一版中。
