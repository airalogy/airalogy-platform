# 第一次使用：先选你要做的事

你不需要先学完所有模块。Airalogy 帮你把研究方案、实际记录、文档和数据放在同一个有权限和历史记录的工作空间里。

[看平台实操入门：填写并保存第一条记录 →](./welcome)

## 你从哪里开始？

| 当前情况 | 第一步 | 演示 |
| --- | --- | --- |
| 收到项目邀请 | 接受邀请，进入该项目；已有 Protocol 时可直接开始记录 | [填写第一条 Record](./first-record) |
| 同事发来一个 Protocol 链接 | 登录后阅读说明、确认版本；没有权限请联系项目管理员 | [填写第一条 Record](./first-record) |
| 今天准备做一项新实验 | 进入项目，用 Aira 起草，或从模板创建、复用 Protocol | [Aira 创建协议](./aira-protocol) · [从模板开始](./first-protocol) |
| 有想法、会议内容或临时观察要记录 | 进入“文档”，个人空间可直接开始，不要求先建立 Protocol | [写第一份文档](./first-document) |
| 已经有 Excel / CSV 数据 | 找到匹配的 Protocol，下载模板后整理；没有合适的 Protocol 时先创建 | [导入第一份 CSV](./first-import) |
| 刚为实验室搭好平台 | 管理员先准备项目和成员权限，再邀请同事 | [实验室管理](../lab-admin/) |

## 先认识四个常用对象

- **项目 Project**：围绕一项研究组织协议、文档、资料和知识，是团队工作的主要入口。
- **协议 Protocol**：可编辑、可版本化的方案，以及要采集的字段结构。可为一次实验新建，也可反复复用。
- **记录 Record**：基于某个准确版本的 Protocol 提交的数据；修改保留修订历史。
- **文档**：灵活记录想法、方案、观察或会议，可按需要逐步加入字段，无需预先准备独立 Protocol。

Lab 是团队、权限和资源的归属。在单实验室部署中，界面会自动使用固定实验室；成员通常从项目开始。个人文档仅自己可见；项目、实验室内容依授权共享。**公开项目不意味着其中每一种文档或资料都自动公开。**

## 让 Aira 帮你开始

实例开启 AI 后，可以直接描述目标，再核对、确认并保存结果。下面三段视频均调用真实模型，使用虚构教学数据。

1. [用 Aira 创建并完善 Protocol](./aira-protocol)：描述需求 → 生成草稿 → 对话修改 → 校验预览 → 保存。
2. [与 Aira 对话填写 Record](./aira-record)：先问字段 → 指定数值 → 逐字段接受或保留 → 手动修改 → 提交。
3. [向 Aira 提问并保存分析结果](./aira-analysis)：提问 → 采用建议 → 确认计算 → 查看来源 → 保存分析方法。

Aira 帮助起草、填写和解释；保存位置、权限、校验和执行结果仍在平台界面确认。AI 未启用时，下方手工路径完整可用。

## 四个手工操作入门任务

1. [填写并找回第一条 Record](./first-record)：保存、确认结果、修订。
2. [写下第一份研究文档](./first-document)：选模板、写内容、找回。
3. [从模板建立第一个 Protocol](./first-protocol)：编辑、校验、预览、保存。
4. [导入第一份 CSV 表格](./first-import)：标准模板、报错、更正、确认导入。

每个任务都有真实界面视频、中文 AI 配音、中英文字幕、操作步骤和完成检查。点击播放后才会发声，可随时静音或切换字幕。示例数据均为虚构，AI 演示需要模型服务；四个手工任务不需要 AI 服务或实验设备。使用专用演示项目；不要混入正式科研数据。同一项目已有示例 Protocol 时直接复用即可。

## 管理员只需先做好这些准备

- 确认实验室与项目归属，配置成员的读写权限。
- 在专用演示项目中导入示例 Protocol，供新成员跟做。
- 邀请成员加入，并告诉他们从哪个项目或 Protocol 开始。

教程不会自动创建项目、扩大权限或把模拟值提交到正式研究中。后续可继续学习[知识与资料相关研究流程](../user-guide/research-documents)、[协作](../user-guide/collaboration)和[科研自动化](../user-guide/research-automation)。
